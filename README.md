# PE Civil Structural Study Collection

Organized practice materials and study references. Files are named by actual content.

## Focused study package

The focused ZIP contains only PE practice exams, practice problems, and the single integrated GPT Review & Code Lookup PDF. FE supplements, priority answer sets, code references and California licensure materials are available only in the full collection.

## Organization notes

- One complete Learnova Q1-Q501 problem book is retained; annotation and download duplicates are omitted.
- Different exam editions remain separate.
- The original download ZIP is omitted because its PDFs are already filed individually.
- Code Lookup is one indexed PDF with three sections; the all-code section takes precedence where later corrections overlap.
- Personal exam schedule text, print timestamps, PDF creation/modification metadata, and personal annotations are omitted.
- Publication dates, code editions, registration watermarks and generic examination instructions remain part of the source materials.
- GPT references are study aids. Code editions and source conditions must be checked when applying technical guidance.
